# Student Performance Analyzer

## About the Project

The Student Performance Analyzer is a Python-based project that calculates students' marks, percentages, grades, and pass/fail results. It also saves student records in a CSV file.

## Features

* Accepts and validates student names.
* Validates marks between 0 and 100.
* Calculates total marks and percentage.
* Assigns grades based on percentage.
* Checks whether the student has passed or failed.
* Identifies failed subjects.
* Saves student records in a CSV file.
* Displays all saved student records.
* Searches for student records by name.
* Handles invalid inputs.

## Technologies Used

* Python
* CSV module
* OS module

## How to Run

1. Install Python on your computer.

2. Open the project folder in VS Code.

3. Open the terminal.

4. Run the following command:

   `python main.py`

5. Follow the menu options displayed in the terminal.
